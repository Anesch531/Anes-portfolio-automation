# 📊 Review Summarizer

POST a product's raw reviews → get a manager-ready digest card: average
rating, sentiment split, the top themes with ▲/▼ polarity, a 40-word verdict,
and a suggested public reply to the main criticism.

The LLM writes the verdict and reply — but every number, theme, and even the
fallback wording comes from deterministic heuristics computed first. If the
LLM dies mid-demo, the digest still renders (mode: `template`).

## How it works (plain language)

1. **In** — one webhook: `{ "product": "...", "reviews": [{"rating": 5,
   "text": "..."}] }`. `{"demo": true}` runs a bundled realistic sample.
2. **Clean** — ratings coerced to 1–5, junk rows counted-and-skipped, capped
   at 300 reviews per call.
3. **Heuristics first** — stopword-filtered term frequency (each review votes
   once per term so a rant can't spam a theme), each theme scored by the
   average rating of reviews mentioning it → positive / mixed / negative.
   Sentiment split: ≥4★ positive, 3★ neutral, ≤2★ negative.
4. **LLM polish** — gets *only those stats* plus one critical quote; must
   return strict JSON `{themes[], verdict, reply}`. A validator enforces
   shape, lengths, allowed sentiment values.
5. **Ship** — Telegram-style HTML digest over HTTP. Fallback path composes
   verdict + reply straight from the heuristic themes.

## Architecture

```
Webhook ─► Parse+clean ─► Has reviews? ──no──► usage note
                              │yes
                              ▼
                    Heuristic themes + split ─► LLM (strict JSON) ─► Merge/fallback ─► HTML digest
```

| n8n node | Source in `lib/logic.js` |
|---|---|
| Parse reviews | `parseReviews` |
| Extract heuristic themes | `sentimentSplit`, `keywordThemes`, `buildLlmPrompt` |
| Build digest | `mergeDigest`, `formatDigest`, `esc` |

Workflow JSON generated by `node build-workflow.js` from the tested lib.

## Reliability

- LLM node: no retry (cost control), 12s timeout, onError=continue.
- Validator rejects malformed/garbled JSON → template digest ships, mode shown
  honestly in the footer.
- Empty/malformed payloads get a friendly usage note instead of an error page.
- Zero external data sources — works fully offline except the optional LLM call.

## Import & configure (~3 min)

1. Import `workflows/review-summarizer.json`.
2. Attach your Header Auth LLM credential on "Summarize themes with LLM"
   (or delete that node + set merge to template-only for a zero-AI version).
3. Activate. Webhook URL: `/webhook/review-summary`.

## Run the demo

```bash
curl -X POST https://<your-n8n>/webhook/review-summary \
     -H "Content-Type: application/json" -d '{"demo":true}'
```

Or paste a real batch:

```bash
curl -X POST https://<your-n8n>/webhook/review-summary \
     -H "Content-Type: application/json" \
     -d '{"product":"AuroraDesk Pro","reviews":[{"rating":5,"text":"Easy assembly"},{"rating":2,"text":"Motor died, slow support"}]}'
```

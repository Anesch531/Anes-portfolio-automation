# 🧲 Lead Capture → Enriched CRM

A consent-based lead form that does what a $99/mo CRM lite would do:
validates the inquiry, blocks duplicates, enriches it (company guessed from a
work email domain), scores intent with an LLM — with a deterministic rule-score
fallback — appends a clean row to Google Sheets, and pushes the owner a tiered
Telegram alert the moment it lands.

Consent is enforced in code: no checkbox, no pipeline. No harvesting.

## How it works (plain language)

1. **In** — n8n's built-in Form Trigger (free, hosted by your n8n) or the demo
   webhook. The form has a required "I agree to be contacted" checkbox.
2. **Validate** — name/email/consent checked; junk dies quietly.
3. **Dedupe** — email → hash; seen-hashes live in workflow static data for 7
   days. Same person twice = processed once. Demo requests bypass this.
4. **Enrich** — free-provider check (gmail ≠ company), company name inferred
   from the work domain (`maya@acme.co` → Acme), initials for pretty alerts.
5. **Score** — LLM returns strict `{score, reason}` JSON (0–100 buying intent).
   Validator extracts and range-checks it; any garbage → rule-based score
   built from domain type, message detail, and buy-intent words. The alert
   always shows which mode produced the number.
6. **Ship** — exact-column row appended to the `Leads` tab + Telegram alert:
   🔥 Tier A / ⚡ Tier B / 🧊 Tier C with the "why".

## Architecture

```
Form ─┐
      ├─► Validate ─► Is valid? ─► Dedupe(hash) ─► Enrich ─► LLM score ─► Merge(fallback) ─► Build row+alert ─► Is demo?
Demo ─┘                                                                                          ├─ yes ► HTTP answer (no real state)
                                                                                                 └─ no  ► Google Sheet row ─► Telegram [NEW LEAD]
```

| n8n node | Source in `lib/logic.js` |
|---|---|
| Validate lead | `validateLead`, `emailHash` |
| Dedupe by email hash | glue (static-data pattern from docs/n8n-conventions.md) |
| Enrich lead | `enrich`, prompt builder |
| Merge score | `ruleScore`, `mergeLlmScore` |
| Build row and alert | `sheetRow`, `notifyText`, `esc` |
| Emit CRM row | glue |

Workflow JSON generated by `node build-workflow.js` from the tested lib.

## Reliability

- Sheet append fails? `onError: continue` — owner alert still fires.
- LLM down/times out/garbage JSON → rule score ships, flagged `mode=template`.
- Dedupe prunes >7-day keys every run so static data never bloats.
- Demo path answers over HTTP and writes **nothing**: not the sheet, not dedupe.

n8n Form Trigger · Google Sheets API (free consumer account works) ·

## Import & configure (~10 min)

1. Import `workflows/lead-capture.json`.
2. Create a Google Sheet, rename first tab to `Leads`, paste header row:
   `timestamp	name	email	company	message	score	tier	reason	scoreMode	domain`
3. In "Log lead to CRM sheet": paste your sheet URL, pick credential once.
4. Telegram nodes: select your bot credential. Set env var `TELEGRAM_CHAT_ID`
   on your n8n instance (used by "Notify owner").
5. LLM node: attach Header Auth credential like in token-research.
6. Activate — open the Form URL n8n shows and submit a test.

## Run the demo

```bash
curl -X POST https://<your-n8n>/webhook/lead-capture/demo \
     -H "Content-Type: application/json" \
     -d '{"name":"Maya Chen","email":"maya@northbeam-logistics.com","company":"NorthBeam Logistics","message":"We want to automate warehouse status reports. Budget approved.","consent":true}'
```

Returns the `[DEMO]` confirmation card (score + tier). Nothing touches the
sheet, dedupe state, or your real inbox.

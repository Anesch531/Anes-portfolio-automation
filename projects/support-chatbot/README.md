# 💬 Support Chatbot (Telegram)

A client-facing support bot that answers instantly from a knowledge base you
own, escalates to an LLM only when the KB can't help, and tells the truth when
it doesn't know. Commands: `/start`, `/faq`, `/demo` (isolated canned demo),
and typing "human" flags the chat for personal follow-up.

**Why Telegram:** free forever, native n8n triggers, zero verification
friction. The brain (KB retrieval → grounding → fallback) is channel-agnostic;
swapping to WhatsApp Cloud API later is a trigger/reply node swap — the logic
layer doesn't change.

## How it works (plain language)

1. **Route** — every incoming message is classified: command (`/start`,
   `/faq`, `/demo`, `/human`), escalation request ("talk to a person"), or a
   plain question.
2. **Retrieve** — the question is tokenized and scored against the KB
   (fraction of query words found in each entry's question+tags, plus a bonus
   for exact tag hits). Top match ≥ 0.34 confidence ⇒ answer straight from
   the KB. Free, instant, zero hallucination risk.
3. **Ground** — otherwise the full KB is sent as grounding context to the
   LLM with a strict system prompt ("answer ONLY from this context"). A
   validator checks the reply; on any failure an honest template ships:
   *"flagged for the team, type /faq or say human."*
4. **Tag honestly** — every reply footer shows its source: 📖 from the FAQ,
   🤖 AI-assisted, 📮 forwarded to a human.

## Architecture

```
Telegram ─► Load KB ─► Route ── commands/demo ──► Compose reply ─► send
                          │ question
                          ▼
                   Retrieve top matches ─► Confident? ──yes──► KB answer ─► send
                          │ no                     │no
                          └────► LLM (grounded) ◄──┘ ─► Ground-or-fallback ─► send
```

| n8n node | Source in `lib/logic.js` |
|---|---|
| Load knowledge base | `SAMPLE_KB` (serialized from the tested lib) |
| Route message | `shouldEscalate` |
| Compose command reply | `commandReply`, `retrieve`, `decide`, `formatAnswer` |
| Find best answers | `normalize`, `tokenize`, `retrieve`, `decide` |
| Answer from knowledge base | `formatAnswer` |
| Ground or fall back | `groundOrFallback`, `formatAnswer` |

Workflow JSON generated by `node build-workflow.js` — constants are serialized
from the tested module, so repo code and n8n nodes can't drift.

## Reliability

- KB path never calls external services — instant even during an LLM outage.
- LLM: 12s timeout, no blind retries, output validated before sending.
- Unknown questions get honest fallbacks, never invented prices.
- Escalation regex catches "human / agent / real person / talk to someone".
- `/demo` runs the real pipeline on a canned question, marked 🧪 [DEMO].

## Free tiers used

Telegram Bot API (free) · optional per-call LLM key (n8n Credentials only).
The KB-first design means most traffic costs $0.

## Import & configure (~5 min)

1. Import `workflows/support-chatbot.json`.
2. Both Telegram nodes: select your bot credential.
3. Edit the KB in **Load knowledge base** (or in `lib/logic.js` +
   re-run build): replace TODO_PRICE / TODO_DAYS / TODO_EMAIL /
   TODO_BUSINESS_NAME with your facts.
4. Attach your Header Auth LLM credential on "Ground with LLM".
5. Activate and message your bot.

## Try it live

- `/start` → greeting · `/faq` → everything it knows
- Ask *"how much does it cost?"* → 📖 KB answer
- Ask *"do you sponsor chess teams?"* → 🤖 grounded answer (or 📮 fallback)
- `/human` → escalation confirmation

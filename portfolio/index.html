Token Research Report Bot

Problem. Checking a token means hopping between five sites and still missing contract risks. Traders want one trustworthy answer in seconds.

What I built. A Telegram command that fuses CoinGecko markets, the deepest DexScreener pool, a GoPlus security check (honeypot, mint rights, taxes, owner holdings) and filtered headlines into one rich report card — then writes a cautious verdict.   • LLM verdict is grounded in fetched facts only, validated, with a deterministic template fallback
  • Primary APIs retry ×3; enrichments degrade gracefully — the report never dies mid-demo
  • Isolated demo endpoint answers over HTTP without touching real chats

Lead Capture → Enriched CRM

Problem. Small businesses lose leads in inbox chaos: no scoring, duplicates, zero instant follow-up.

  • Consent enforced in code — the pipeline refuses to run without it
  • Sheet append failing never blocks the owner alert (error branches everywhere)
  • Demo mode processes a full lead while writing nothing to real state

Review Summarizer

Problem. Shop owners drown in raw reviews and never extract what matters: recurring complaints and praise worth acting on.

What I built. One webhook: messy reviews in → digest out. Deterministic heuristics compute the rating split and themes first (one vote per review per theme, polarity from average rating of mentions); the LLM only writes the verdict and a suggested public reply, returning strict validated JSON.

  • Runs end-to-end with the AI completely off — mode shown honestly in the footer
  • Junk rows skipped and counted; empty payloads get a friendly usage note
  • The cheapest project here to run: zero external data sources

06

case study · the original

Smart Money Alert Bot

Problem. Retail traders see whale moves hours late — after the alpha is gone. Most "whale bots" spam noise: airdrops, wraps, and random transfers all look like trades.

What I built. Real-time Telegram alerts when one of 5 hand-vetted wallets makes a ≥$1,000,000 trade on Ethereum. Alchemy push webhooks (not polling), HMAC-SHA256 signature verification, leg-pairing trade classification that drops airdrops/self-transfers/stable-swaps, quote-leg valuation that prices unlisted tokens correctly, a $1,000,000 gate with 24h dedupe — and an AI one-liner grounded in fetched facts only, with a template fallback.

  • Proven under double-failure: CoinGecko AND the LLM killed simultaneously — the alert still delivered (stale price marked ≈, template sentence)
  • 6 classification fixtures green: buys, sells, unlisted-token buys valued via quote leg; forgeries silently rejected
  • Two legs of the same trade are cross-checked against each other and dropped if they disagree by more than 20% — a price feed cannot publish a wrong number alone
  • A failed send is never recorded as delivered: dedupe commits after the message is confirmed, so nothing is silently swallowed
  • Watchlist is curated evidence: every wallet machine-verified on-chain with public sources

08 — about

I'm Mohammed Anes, an automation builder. I design and ship end-to-end workflows with n8n — data sources in, clean logic in the middle, polished delivery out. Lead pipelines, support bots, reporting, alerting: if a business does it manually and repeatedly, I automate it.

My obsession is the difference between a demo and a product: what happens when an API times out mid-run. Everything I ship has timeouts, retries, dedupe and a fallback path, so the output still lands when a service misbehaves — and the logic is tested against fixtures like production software, because that's what it is.

I learned that the hard way, not from a course.
